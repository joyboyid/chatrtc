bandit-X — Panduan Develop & Deploy ke Internet
=================================================

Aplikasi sudah siap secara teknis untuk diakses dari internet.
Server default bind ke 0.0.0.0 (semua interface).
Yang perlu diatur: jaringan dan hosting, bukan kode.

Alur Develop → Publik
---------------------

  [Lokal]          →  [LAN]              →  [Internet]
  127.0.0.1:8080      192.168.x.x:8080      IP publik / domain:8080

  Tahap 1 — Lokal   : develop di PC sendiri
  Tahap 2 — LAN     : tes di WiFi rumah/kantor
  Tahap 3 — Internet: orang luar bisa join


================================================================================
Opsi 1: VPS (Paling Direkomendasikan)
================================================================================

Sewa server kecil di cloud, deploy binary Rust di sana.

Provider contoh: Hetzner, DigitalOcean, Vultr, AWS Lightsail (~$4–6/bulan)

Langkah deploy:

  # 1. Build release di PC lokal
  cargo build --release

  # 2. Upload ke VPS
  scp target/release/bandit-x user@IP_VPS:/home/user/

  # 3. SSH ke VPS, jalankan server
  ssh user@IP_VPS
  ./bandit-x --server --port 8080 --host 0.0.0.0

Buka firewall di VPS:

  # Ubuntu/Debian (ufw)
  sudo ufw allow 8080/tcp
  sudo ufw enable

  # Atau iptables
  sudo iptables -A INPUT -p tcp --dport 8080 -j ACCEPT

Client dari mana saja:

  cargo run -- --client --addr IP_VPS:8080 --username alice
  cargo run -- --client --addr chat.example.com:8080 -u bob

--------------------------------------------------------------------------
 Hosting TANPA IP PUBLIK (shared hosting / cPanel / Cloudflare)
--------------------------------------------------------------------------

Kalau domain sudah diarahkan ke Cloudflare atau hosting tidak punya IP publik,
TCP mentah tidak akan sampai: Cloudflare hanya meneruskan HTTP/HTTPS, sedangkan
bandit-X bicara TCP biasa. Solusinya: mode WebSocket.

Server bicara WebSocket di port yang sama dengan TCP biasa (mendeteksi sendiri
dari byte pertama koneksi), jadi satu port melayani dua-duanya.

  # 1. Jalankan server, dengarkan hanya di localhost
  ./bandit-x --server --port 8080 --host 127.0.0.1
  # Tidak perlu buka firewall: tidak ada akses langsung dari luar.

  # 2. nginx sebagai reverse proxy + WebSocket upgrade
  #    (path /chat dipakai untuk memisahkan routing dari situs web)
  server {
      listen 443 ssl http2;
      server_name orojackson.xcodehoster.id;

      ssl_certificate     /path/ke/fullchain.pem;
      ssl_certificate_key /path/ke/privkey.pem;

      location /chat {
          proxy_pass http://127.0.0.1:8080;
          proxy_http_version 1.1;

          # Tiga baris ini yang membuat WebSocket jalan.
          proxy_set_header Upgrade    $http_upgrade;
          proxy_set_header Connection "upgrade";
          proxy_set_header Host       $host;

          # Jangan putuskan koneksi yang lama diam.
          proxy_read_timeout  3600s;
          proxy_send_timeout  3600s;
      }
  }

  # Kalau memakai cPanel, buat "Application Manager" atau pakai .htaccess:
  #   Apache butuh mod_proxy_wstunnel, atau setevirtualhost di panel.

  # 3. Cloudflare
  #    - SSL/TLS: mode "Full" atau "Full (strict)"
  #    - WebSocket: menyala secara default, tidak perlu pengaturan
  #    - Pastikan port 80/443 tidak diblokir di firewall Cloudflare

  # 4. Client (teman)
  bandit-x --client --ws --addr wss://orojackson.xcodehoster.id/chat -u budi
  cargo run -- --client --ws --addr wss://orojackson.xcodehoster.id/chat -u budi

  wss:// memakai TLS ke Cloudflare, lalu Cloudflare Speak HTTP biasa ke
  server. Kalau hosting punya sertifikat sendiri, pakai ws:// (tanpa TLS)
  sebagai gantinya:

  bandit-x --client --ws --addr ws://orojackson.xcodehoster.id/chat -u budi

Catatan:
  - Path (/chat) bebas diganti, itu urusan nginx. bandit-X menerima path apa saja.
  --Port 8080 tidak perlu dibuka ke publik untuk mode ini.
  - Kalau shared hosting tidak bisa menjalankan proses 24 jam, pakai Railway,
    Fly.io, atau VPS murah (Linode $3.5/bulan) yang punya IP publik.

Agar server tetap jalan (systemd):

  # /etc/systemd/system/bandit-x.service
  [Unit]
  Description=bandit-x server
  After=network.target

  [Service]
  ExecStart=/home/user/bandit-x --server --port 8080 --host 0.0.0.0
  Restart=always
  User=user

  [Install]
  WantedBy=multi-user.target

  sudo systemctl enable --now bandit-x


================================================================================
Opsi 2: PC Rumah + Port Forwarding
================================================================================

Tanpa VPS — pakai PC/Manjaro sebagai server.

  1. Jalankan server:
     ./bandit-x --server --port 8080

  2. Cek IP lokal:
     ip addr
     # misalnya: 192.168.1.10

  3. Tes LAN dulu:
     cargo run -- --client -a 192.168.1.10:8080 -u alice

  4. Login ke router → Port Forwarding:
     external port 8080 → 192.168.1.10:8080

  5. Cek IP publik:
     curl ifconfig.me

  6. Client dari luar:
     cargo run -- --client -a IP_PUBLIK:8080 -u bob

Kekurangan:
  - IP rumah bisa berubah → pakai Dynamic DNS (No-IP, DuckDNS)
  - PC harus nyala terus
  - ISP kadang blok port atau tidak beri IP publik (CGNAT)


================================================================================
Opsi 3: Tunnel (Cepat untuk Testing / Demo)
================================================================================

Tanpa buka port router. Cocok untuk demo cepat ke teman.

ngrok:

  # Terminal 1 — server lokal
  cargo run -- --server --port 8080

  # Terminal 2 — tunnel
  ngrok tcp 8080
  # Output contoh: tcp://0.tcp.ngrok.io:12345

  # Client connect:
  cargo run -- --client -a 0.tcp.ngrok.io:12345 -u alice

Alternatif: Cloudflare Tunnel — gratis, lebih stabil untuk production ringan.


================================================================================
Mode P2P (--peer) Lewat Internet — TANPA Server Pusat
================================================================================

P2P bandit-X memang dirancang untuk tanpa server pusat, TAPI tetap butuh
minimal satu node yang BISA DIJANGKAU dari luar (IP publik / port-forward /
VPN). Koneksinya TCP murni, jadi:

  - Node yang DIAL (--connect) bisa di balik NAT mana pun. ✅
  - Node yang DI-DIAL (yang --listen-nya dituju) HARUS reachable. ⚠️

Cara paling mudah memulai cross-internet:

  Node 1 (publik, mis. VPS / PC dengan port-forward):
    ./bandit-x --peer --listen 0.0.0.0:9090 --username alice

  Node 2 (rumah, balik NAT) → dial node 1:
    ./bandit-x --peer --listen 127.0.0.1:9091 --username bob \
       --connect IP_PUBLIK_ALICE:9090

  Node 3 (mana saja) → cukup kenal node 1 ATAU node 2:
    ./bandit-x --peer --listen 0.0.0.0:9092 --username carol \
       --connect IP_PUBLIK_ALICE:9090
    # Node 1 memperkenalkan node 2 ke node 3 (gossip), keduanya langsung
    # terhubung peer-to-peer tanpa melewati server mana pun.

Catatan penting P2P:
  - Setiap node butuh --listen UNIK (port beda / host beda).
  - Untuk bisa DI-DIAL orang lain, --listen harus alamat yang benar-benar
    bisa dijangkau (mis. IP publik atau IP LAN), BUKAN 0.0.0.0 saja.
  - Gossip otomatis menolak alamat liar (0.0.0.0/::) dan alamat sendiri.
  - Trik tanpa --connect di semua node: SATU node publik saja sudah cukup
    jadi "seed" — sisanya saling kenal lewat perkenalan (Introduce).
  - Belum ada NAT traversal: node di balik CGNAT/koneksi telat tidak bisa
    di-dial langsung (hanya bisa dial keluar). Itu roadmap.

Testing tanpa internet: jalankan beberapa node di satu mesin (port beda-beda)
  ./target/debug/bandit-x --peer --listen 127.0.0.1:9001 -u alice
  ./target/debug/bandit-x --peer --listen 127.0.0.1:9002 -u bob --connect 127.0.0.1:9001
  ./target/debug/bandit-x --peer --listen 127.0.0.1:9003 -u carol --connect 127.0.0.1:9001

Distribusi ke User Lain
================================================================================

User lain perlu:
  1. Install Rust, ATAU
  2. Download binary siap pakai dari kamu

Build & kirim binary:

  cargo build --release
  # File: target/release/bandit-x
  # Kirim ke user, lalu:
  ./bandit-x --client --addr IP_SERVER:8080 --username nama_mereka

Bisa juga publish di GitHub Releases agar orang download tanpa compile.

Cross-compile (opsional):

  # Linux → Windows
  rustup target add x86_64-pc-windows-gnu
  cargo build --release --target x86_64-pc-windows-gnu

  # Cara termudah: build langsung di mesin target (Windows/macOS/Linux)

Checklist Sebelum Go Public
================================================================================

  [✓] Bind 0.0.0.0         — sudah default, terima koneksi dari luar
  [✓] Mode P2P (--peer)    — mesh tanpa server, gossip alamat antar node
  [ ] Firewall port terbuka — atur manual di VPS/router
  [ ] TLS/encryption       — belum ada, traffic plain TCP
  [ ] Autentikasi          — belum ada, siapa saja bisa join
  [ ] Rate limiting        — belum ada, rentan spam

PENTING: Versi sekarang belum aman untuk production serius.
Pesan dikirim tanpa enkripsi, tidak ada password.
Untuk teman/komunitas kecil masih OK.
Untuk publik luas → perlu TLS + auth.

Rekomendasi per Tujuan
================================================================================

  Belajar & tes sendiri     → Lokal + LAN
  Demo ke teman (cepat)     → ngrok / Cloudflare Tunnel

================================================================================
Install di Semua Sistem Operasi
================================================================================

Ada 3 cara distribusi. Pilih sesuai kebutuhan:

  A. GitHub Releases + script install   ← direkomendasikan untuk end-user
  B. cargo install --git ...            ← untuk user yang sudah punya Rust
  C. Build manual per platform          ← untuk maintainer


--------------------------------------------------------------------------------
A. GitHub Releases (Otomatis Multi-Platform)
--------------------------------------------------------------------------------

Project sudah punya workflow CI:
  .github/workflows/release.yml

Build otomatis untuk:
  - Linux x86_64
  - Linux ARM64 (Raspberry Pi, VPS ARM)
  - Windows x86_64
  - macOS x86_64 (Intel)
  - macOS ARM64 (Apple Silicon)

Langkah publish release:

  1. Push project ke GitHub
  2. Commit & tag versi:
     git tag v0.1.0
     git push origin v0.1.0
  4. GitHub Actions otomatis build & upload ke Releases

User install (Linux / macOS):

  # Ganti USER dengan username GitHub kamu
  export BANDIT_X_REPO="joyboyid/bandit-X"
  curl -fsSL https://raw.githubusercontent.com/joyboyid/bandit-X/main/scripts/install.sh | bash

  # atau versi tertentu
  ./scripts/install.sh --version v0.1.0

User install (Windows PowerShell):

  $env:BANDIT_X_REPO = "joyboyid/bandit-X"
  irm https://raw.githubusercontent.com/joyboyid/bandit-X/main/scripts/install.ps1 | iex

  # atau
  .\scripts\install.ps1 -Version v0.1.0

Setelah install:

  bandit-x --server
  bandit-x --client -a SERVER:8080 -u username


--------------------------------------------------------------------------------
B. cargo install (dari source Git)
--------------------------------------------------------------------------------

Untuk user yang sudah install Rust:

  cargo install --git https://github.com/joyboyid/bandit-X.git --tag v0.1.0

Binary masuk ke ~/.cargo/bin/ (pastikan ada di PATH).


--------------------------------------------------------------------------------
C. Build Manual (Maintainer)
--------------------------------------------------------------------------------

Build semua target yang tersedia di mesin kamu:

  chmod +x scripts/build-all.sh
  ./scripts/build-all.sh

Output ada di folder dist/:
  bandit-x-0.1.0-x86_64-unknown-linux-gnu.tar.gz
  bandit-x-0.1.0-x86_64-pc-windows-msvc.zip
  dst.

Kirim file yang sesuai OS user, extract, lalu jalankan binary.
